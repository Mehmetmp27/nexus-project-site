# NEXUS-v2 — Official Project Website & Cognitive Showcase

> **Canlı Site:** [https://mehmetmp27.github.io/nexus-project-site/](https://mehmetmp27.github.io/nexus-project-site/)

Bu depo, **NEXUS-v2 / NEXUS Living Cognitive System** projesinin resmî vitrin ve tanıtım web sitesini barındırır.

---

## 🌟 Proje Özeti

NEXUS; Mehmet'in kontrolünde çalışan; farklı yapay zekâ sağlayıcılarını (OpenAI, Google Gemini, Anthropic, DeepSeek, xAI, Ollama), yerel modelleri, uzman ajanları ve masaüstü araçlarını ortak bir hafıza, kimlik, bağlam, planlama, güvenlik, görev yönetimi ve doğrulama katmanında birleştiren **kişisel dijital bilişsel işletim sistemidir**.

### Sitede Öne Çıkan Başlıklar
1. **NEXUS-01 Varlık ve Biyometrik Kimlik:** Onaylı kanonik referans (`1000321941.png`), 9 ifadeli mimik matrisi, göz & iris detayları, anatomik ve stüdyo çok açılı modelleme çizelgeleri.
2. **6 Temel Bilişsel Katman:** Identity, Memory Fabric (SQLite M3), Model Mesh, Task Manager & Checkpoints, Capability-Scoped Policy & Audit, Computer Control.
3. **İnteraktif Masaüstü Kokpiti (Live Simulator):** Focus, Operations ve Compact masaüstü modları ile gerçek zamanlı BIST analizi, M3 yetki iptali ve sesli senkron simülasyonu.
4. **Uzman Ajan Kataloğu:** Planner/Supervisor, Finance Analyst, Coding Agent, Security Agent, Web Research Agent, Computer Control Agent.
5. **Mühendislik Gap Matrisi:** Gerçek masaüstü test kanıtlarına dayanan şeffaf durum tablosu.
